# Changelog

## v1.0 — 2025-12-13

First release.

- Slide-in overlay for game trainers, driven by controller or keyboard
- XInput (Xbox, ROG Ally) and DirectInput (PS4, PS5) controller support
- JSON trainer library with toggle and one-shot cheats
- Download trainer packs from this repo inside the app
- System tray icon and Steam-style UI sounds
- Installer and portable builds
