# Privacy

Trainer Overlay doesn't collect, store or send any personal data, and it has no analytics or telemetry.

The only time it goes online is when you open **Download Cheats**. It then asks the GitHub API for the list of files in this repo's `remote_trainers` folder and downloads the pack you choose. Those requests go to GitHub, under [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

Everything else, including the trainers you load and your settings, stays on your PC.
